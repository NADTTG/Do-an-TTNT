# Bài toán 8 Quân Hậu

Ứng dụng Python Tkinter mô phỏng và giải bài toán 8 quân hậu bằng:
- DFS
- BFS với Priority Queue (heapq)
- Hill Climbing

## Mục tiêu
- Minh họa bài toán 8-Queens trong AI
- So sánh các hướng tìm kiếm và tối ưu hóa
- Hiển thị trực quan nghiệm trên bàn cờ

## Tính năng
- Chọn thuật toán bằng radio button
- Hiển thị bàn cờ 8x8
- Duyệt qua nhiều nghiệm với DFS/BFS
- Hill Climbing tìm nghiệm nhanh hơn nhưng không đảm bảo mọi nghiệm

## Cách chạy
```bash
pip install -r requirements.txt
python app.py
